# تركيب سيرفر دوايا على كمبيوتر الصيدلية (ويندوز)

السيرفر هو يلي بيخلّي كل أجهزة الصيدلية (كمبيوتر الكاونتر، والموبايلات، ولابتوب تاني) تتشارك نفس البيانات على **الواي فاي تبع الصيدلية**، بدون ما يلزم إنترنت.

- إذا السيرفر طفي، كل جهاز بيضل يبيع عادي، وبيزامن لحاله أول ما يرجع السيرفر.
- كل جهاز معه نسخة كاملة من البيانات، يعني إذا خرب هارد الكمبيوتر ما بتضيع البيانات.

> **شو بيلزم:** كمبيوتر ويندوز 10 أو 11 بيضل شغّال وقت دوام الصيدلية (ممكن يكون نفسه كمبيوتر الكاونتر)، ونص ساعة وقت، وإنترنت **بس وقت التركيب** لتنزيل البرامج.

---

## 1) تنزيل البرامج (مرة وحدة)

1. **Python** (نسخة 3.11 أو أحدث) من python.org.
   - بأول شاشة من التركيب علّم على **«Add python.exe to PATH»**.
2. **PostgreSQL 16** من postgresql.org (Windows installer).
   - وقت التركيب رح يطلب **كلمة سر للمستخدم `postgres`**. اكتبها بورقة وخبّيها، رح نحتاجها بالخطوة 3.
   - خلّي باقي الخيارات متل ما هي (المنفذ 5432).
3. **ملفات دوايا:** انسخ مجلد المشروع لـ `C:\Doaya`.
   - لازم يكون المسار كله بأحرف إنكليزية بس.

## 2) خلّي الواي فاي «خاصة» (Private)

- الإعدادات ← الشبكة والإنترنت ← الواي فاي ← اسم الشبكة ← نوع الشبكة: **Private (خاصة)**.
- هيك الموبايلات بتقدر تلاقي الكمبيوتر على الشبكة.

## 3) التركيب (أمر واحد)

1. افتح **PowerShell كمسؤول** (كليك يمين على قائمة ابدأ ← Terminal (Admin)).
2. اكتب:
   ```powershell
   cd C:\Doaya
   powershell -ExecutionPolicy Bypass -File backend\deploy\windows\install.ps1
   ```
3. لما يسألك عن كلمة سر `postgres`، اكتب يلي اخترتها بالخطوة 1.

السكربت بيعمل كل شي لحاله:
- بينزّل مكتبات السيرفر.
- بيعمل قاعدة بيانات `doaya` بكلمة سر عشوائية قوية.
- بيجهّز الجداول.
- بيفتح المنفذين 8000 و47800 بجدار حماية ويندوز.
- بيخلّي السيرفر **يشتغل لحاله مع كل تشغيل للكمبيوتر**، وإذا وقف بيرجع يقوم بعد دقيقة.

بالآخر بيطبع شي متل:
```
Server is running: ok
Server code (the devices show it when linking): 6E9B-8AA7
Address for the app: 192.168.1.10:8000
```
- **العنوان** منستعمله إذا ما لقى التطبيق السيرفر لحاله.
- **رمز السيرفر** اكتبه بورقة. الاتصال بين الأجهزة والسيرفر مشفّر، وهاد الرمز هو «هوية» السيرفر. وقت تربط أي جهاز، التطبيق بيورجيك الرمز، ولازم يكون نفسه.
- إذا نسيته: `.\.venv\Scripts\python.exe -m app.cli server-code` (من مجلد `C:\Doaya\backend`).

## 4) ربط الأجهزة

1. **كمبيوتر الكاونتر:**
   - من التطبيق روح لـ «السيرفر والمزامنة» ← «دوّر على السيرفر».
   - تأكد إنو «رمز السيرفر» يلي حدّ اسمه نفس الرمز يلي طلع بالخطوة 3، وبعدين اختاره.
   - اكتب رقم موبايلك وكلمة سر جديدة ← «أنشئ واربط».
   - بترتفع كل بيانات الكاونتر للسيرفر.
2. **حسابات الموظفين:** من نفس الشاشة، «حساب لموظف» لكل واحد (رقم + كلمة سر).
3. **كل موبايل:**
   - أول ما تفتح التطبيق اختار «انضمام لصيدلية موجودة».
   - اكتب اسم الجهاز، واختار السيرفر (وقارن رمزه)، وبعدين رقم صاحب الموبايل وكلمة سره.
   - بتنزل كل البيانات، وبيفتح على حسابه مباشرة.

## 5) النسخ الاحتياطي (تلقائي)

- السيرفر بياخد **نسخة احتياطية كاملة كل يوم** بـ `C:\Doaya\backend\data\backups`، وبيحتفظ بآخر 30 نسخة.
- آخر نسخة بتبيّن بشاشة «السيرفر والمزامنة» عند صاحب الصيدلية.
- **ننصح** كل أسبوع تنسخ مجلد `backups` لفلاشة، منشان تضل البيانات بأمان حتى لو صار شي للكمبيوتر كله.

نسخة يدوية هلق (بـ PowerShell):
```powershell
cd C:\Doaya\backend
.\.venv\Scripts\python.exe -m app.cli backup
```

## 6) الاسترجاع من نسخة احتياطية

⚠️ الاسترجاع بيمسح بيانات السيرفر الحالية وبيحط محلها النسخة.

1. **وقّف السيرفر:**
   ```powershell
   Stop-ScheduledTask -TaskName DoayaServer
   ```
2. **شوف النسخ الموجودة:**
   ```powershell
   cd C:\Doaya\backend
   .\.venv\Scripts\python.exe -m app.cli list-backups
   ```
3. **استرجع النسخة يلي بدك ياها:**
   ```powershell
   .\.venv\Scripts\python.exe -m app.cli restore data\backups\doaya-20261001-020000.dump
   ```
4. **شغّل السيرفر من جديد:**
   ```powershell
   Start-ScheduledTask -TaskName DoayaServer
   ```

**تذكير:** حتى بدون نسخة احتياطية، الأجهزة نفسها معها كل البيانات. لو ركّبت سيرفر جديد فاضي واربطت كمبيوتر الكاونتر فيه، بيرفع كل شي من جديد.

## 7) إذا صار شي

| المشكلة | الحل |
|---|---|
| التطبيق ما لقى السيرفر | تأكد إنو الموبايل على نفس الواي فاي، والشبكة «خاصة» (الخطوة 2). أو اكتب العنوان يلي طلع بالخطوة 3 يدوي. |
| «السيرفر مو موجود» بأعلى الشاشة | الكمبيوتر طفي أو الواي فاي مقطوع. البيع شغّال عادي، والمزامنة بتصير لحالها لما يرجع. |
| «السيرفر تغيّر» | يلي عم يرد على عنوان السيرفر شهادته مختلفة، فالجهاز وقّف المزامنة منشان ما تطلع البيانات لجهاز غريب. البيع شغّال عادي. إذا انعاد تركيب السيرفر من الصفر (أو انمسح مجلد `data`)، اضغط «اربط من جديد» على كل جهاز. إذا لا، في شي غريب على الشبكة: لا تربط وشوف مين. |
| «الجهاز مفصول» | صاحب الصيدلية فصل الجهاز. اربطه من جديد برقم وكلمة سر. |
| نسيت كلمة السر | على كمبيوتر السيرفر: `.\.venv\Scripts\python.exe -m app.cli reset-password 0944123456 كلمة-جديدة` |
| بدك تشوف شو صار بالسيرفر | الملف `C:\Doaya\backend\data\server.log` |
| تحديث دوايا لنسخة جديدة | انسخ الملفات الجديدة فوق القديمة، وشغّل `install.ps1` مرة تانية. بيحافظ على البيانات والإعدادات والشهادة (مجلد `data`). |
