**شو خالص بالمحاسبة (1.5):**
- المشتريات: موردين، فواتير شراء، كشف حساب، دفعات، مرتجع للمستودع.
- الأرباح والتكلفة.
- النواقص والطلبيات، مع إرسال الطلبية على واتساب.
- الجرد بدون ما يوقف البيع.
- المصاريف (من الصندوق أو من برّا) والأرباح والخسائر الشهرية.
- نسخة احتياطية يومية تلقائية على الجهاز (مجلد أو فلاشة) مع استرجاع.

**شو خالص بالسيرفر (2):**
- سيرفر FastAPI مع PostgreSQL: حسابات، ربط أجهزة، فصل أجهزة، ومزامنة (رفع وتنزيل).
- محرّك المزامنة جوّا التطبيق، مع صندوق صادر بيتعبّى تلقائياً من قاعدة البيانات.
- شاشة «السيرفر والمزامنة»:
  - اكتشاف السيرفر على الواي فاي.
  - إنشاء الصيدلية على السيرفر، أو الربط برقم وكلمة سر.
  - مؤشّر مزامنة حقيقي بأعلى الشاشة.
  - للمالك: الأجهزة وحسابات الموظفين.
  - «انضمام لصيدلية موجودة» من أول شاشة، وحساب الموظف بيفتح لحاله.
- تجربة حقيقية على لينكس بجهازين: البيع على الجهاز التاني بيبيّن على الكاونتر.
- تجربة كاملة من أولها لآخرها مع السيرفر الحقيقي، ونجحت.
- **تشفير الواي فاي:**
  - السيرفر صار يشتغل HTTPS بشهادة بيعملها لحاله.
  - كل جهاز بيحفظ بصمة الشهادة أول ما ينربط، وبيرفض أي شهادة غيرها.
  - الرمز القصير (متل `AB12-CD34`) بيبيّن بالتطبيق وبيطبعه المركّب منشان تقارنهن.

**عدد الاختبارات:** السيرفر 189، والمنطق (`doaya_core`) 95، ونظام التصميم 23، وتطبيق الصيدلية 97، وتطبيق المريض 27، وفوقهم تجربة المزامنة الكاملة (على HTTPS).

**طباعة الإيصال خالصة:** بعد كل بيعة بيطلع زر «اطبع الإيصال» (ورق 80 مم، أي طابعة). مثال: `docs/screenshots/phase3/22-receipt-sample.pdf`.

**أسئلة لسا ناطرة جواب صاحب المشروع:** ما في هلق.

## 2) تجهيز جهازك مرة وحدة

```bash
git clone https://github.com/5466676/pharmacy-app.git && cd pharmacy-app
git checkout claude/new-session-kppq6z
# Flutter stable (3.47 أو أحدث)، Dart 3.13
flutter pub get
# السيرفر: Python 3.11+، PostgreSQL 16
cd backend && python -m venv .venv
.venv/Scripts/pip install -e ".[dev]"      # على ويندوز (على لينكس: .venv/bin/pip)
# بقاعدة البيانات:
#   CREATE ROLE doaya LOGIN PASSWORD 'doaya' CREATEDB;
#   CREATE DATABASE doaya_test OWNER doaya;
```

- `cd packages/doaya_core && dart test`
- `cd apps/pharmacy && flutter test`
- `cd backend && .venv/bin/pytest`
- `flutter analyze`
- `./tool/sync_e2e.sh`

## 2.5) تجربة المنصة كاملة على جهازك (متل ما جرّبتها بالسحابة)

قبل ما تبلّش:
- الصيدلي بيشتغل بتطبيق الصيدلية، والمريض بتطبيق المريض (عالمتصفح أسهل شي).
- «جرعاتي» والإشعارات بتشتغل على موبايل أندرويد بس؛ عالمتصفح بتشوف المواعيد.

1. **قواعد البيانات** (PostgreSQL):
   ```bash
   createdb -U doaya doaya_central && createdb -U doaya doaya_run
   cd backend
   DOAYA_DATABASE_URL=postgresql+psycopg://doaya:doaya@localhost:5432/doaya_central .venv/bin/alembic upgrade head
   DOAYA_DATABASE_URL=postgresql+psycopg://doaya:doaya@localhost:5432/doaya_run .venv/bin/alembic upgrade head
   ```
2. **LM Studio**:
   - نزّل نموذج صغير بيحكي عربي، متل `qwen2.5-7b-instruct`.
   - شغّل «Local Server» على المنفذ 1234.
3. **دوايا أونلاين** (السيرفر المركزي). `DOAYA_CORS_ORIGINS` منشان تطبيق المريض بالمتصفح يقدر يحكي معه:
   ```bash
   DOAYA_DATABASE_URL=postgresql+psycopg://doaya:doaya@localhost:5432/doaya_central DOAYA_DATA_DIR=data-central \
   DOAYA_CORS_ORIGINS=http://localhost:8200 \
   DOAYA_LLM_MODEL=qwen2.5-7b-instruct .venv/bin/uvicorn app.main:create_app --factory --host 0.0.0.0 --port 8100
   ```
   وبشباك تاني:
   ```bash
   export DOAYA_DATABASE_URL=postgresql+psycopg://doaya:doaya@localhost:5432/doaya_central
   ID=$(.venv/bin/python -m app.cli create-pharmacy --name "صيدلية الشفاء" --owner-name سامر --owner-phone 0944123456 --password secret-1)
   .venv/bin/python -m app.cli list-pharmacy $ID --code SH4F --city دمشق
   .venv/bin/python -m app.cli pharmacy-key $ID      # انسخ المفتاح
   ```
4. **سيرفر الصيدلية** (HTTPS):
   ```bash
   DOAYA_DATABASE_URL=postgresql+psycopg://doaya:doaya@localhost:5432/doaya_run DOAYA_DATA_DIR=data-pharmacy \
   DOAYA_HTTP_PORT=8443 .venv/bin/python -m app.serve
   ```
   بيطبع رمز السيرفر.
5. **تطبيق الصيدلية**: `cd apps/pharmacy && flutter run -d windows` (أو `-d linux`).
   - «السيرفر والمزامنة» ← اكتب `127.0.0.1:8443` ← قارن الرمز ← أنشئ واربط.
   - بنفس الشاشة، «دوايا أونلاين»: العنوان `http://127.0.0.1:8100` والمفتاح يلي نسخته.
6. **تطبيق المريض** عالمتصفح (Chrome أو Edge):
   ```bash
   cd apps/patient
   flutter run -d chrome --web-port 8200 --dart-define=DOAYA_API=http://127.0.0.1:8100
   ```
   - «حساب جديد» ← اختار «صيدلية الشفاء» (أو اكتب الرمز `SH4F`) ← «ابدأ استشارة».
   - احكي متل «عندي صداع من يومين وحرارة خفيفة»، وجاوب أسئلة المساعد، وراجع الملخص ← «ابعته للصيدلية».
   - بعد 15 ثانية بتبيّن الحالة بـ «الحالات» بتطبيق الصيدلية. أي شي بيعمله الصيدلي (بلّش التحضير، القرار) **بيبيّن عند المريض لحاله** بدون تحديث.
   - جرّب «عندي وجع بصدري» لتشوف شاشة الطوارئ (110 و112)، و«شو باخد للصداع؟» لتشوف إنو المساعد ما بيعطي دوا.
   - على موبايل أندرويد بالمحاكي: `flutter run -d emulator-5554 --dart-define=DOAYA_API=http://10.0.2.2:8100` (الـ http العادي مسموح بنسخة التجربة بس).
   - **الرفوف والطلب**: من الرئيسية «متوفر بصيدليتك» ← دوا ← «اطلب من صيدليتي» ← الطلبية (فيك ترفق صورة وصفة) ← «أرسل الطلب». بتطلع بـ «الحالات ← الطلبات» عند الصيدلي مع الصورة.
   - **جرعاتي**: لما الصيدلي يعطي دوا مع «عدد المرات باليوم»، بيطلع «ذكّرني بالجرعات» تحت قراره.
   - **إذا كانت قواعد البيانات عندك من قبل**: أعد `alembic upgrade head` (الخطوة 1) منشان جدول الصور الجديد (`0003`).

## 4) برومتات الخطوات الباقية (بالترتيب المقترح)

### المرحلة 2، الخطوة 6: ✅ خالصة (البرومت انشال)

### المرحلة 2: التجربة على الأجهزة الحقيقية (على جهازك، لأنها ما بتصير بالسحابة)
```
المرحلة 2 خالصة بالكود. المطلوب تجربة حقيقية:
1) على كمبيوتر ويندوز: اتبع docs/INSTALL_SERVER.md وشغّل backend/deploy/windows/install.ps1.
   هالسكربت ما انجرّب على ويندوز حقيقي. إذا فشلت أي خطوة، صلّحها بأقل تغيير، وحدّث الدليل.
2) cd apps/pharmacy && flutter build apk --release (بدو Android SDK)، ونزّله على موبايل على نفس الواي فاي.
3) السيناريو:
   - الكاونتر بينشئ الصيدلية على السيرفر.
   - الموبايل بينضم.
   - بيعوا من الجهازين.
   - طفّي السيرفر، وبيع من الموبايل.
   - رجّع السيرفر، وتأكد إنو الكاونتر شاف البيعة.
   - تأكد إنو النسخة الاحتياطية انعملت بـ backend\data\backups.
سجّل النتيجة بـ docs/PROGRESS.md.
```

### المرحلة 3: تطبيق المريض والذكاء الاصطناعي (الخطوة 8، على جهازك)
```
كمّل المرحلة 3 الخطوة 8 حسب docs/PROGRESS.md (الخطوات 1–7 خالصة، والقرارات بـ DECISIONS).
الخطوة 8 تجربة حقيقية، ما في كود جديد إلا تصليح يلي بيطلع:
1) شغّل LM Studio بنموذج بيحكي عربي (متل qwen2.5-7b-instruct) على المنفذ 1234، والسيرفر المركزي وسيرفر الصيدلية متل قسم 2.5 بـ docs/HANDOFF.md.
2) من تطبيق المريض (عالمتصفح وعلى موبايل أندرويد): استشارة عادية لحد الاستلام، حالة خطرة («عندي وجع بصدري»)، سؤال عن دوا («شو باخد للصداع؟») ولازم ما يعطي دوا ولا جرعة.
3) طفّي LM Studio بنص محادثة: لازم يعرض «ابعت المحادثة للصيدلي مباشرة».
4) افصل الإنترنت عن سيرفر الصيدلية: البيع بيضل شغّال، والحالات بتقول ما في إنترنت.
5) على الموبايل: «ذكّرني بالجرعات» ← لازم يوصل إشعار بالوقت؛ سكّر التطبيق وخلّي الصيدلي يجهّز طلب ← لازم يوصل «طلبك جاهز» خلال ربع ساعة تقريباً.
6) اطبع إيصال على طابعة الصيدلية.
سجّل كل شي بـ PROGRESS مع صور، وصلّح أي غلط مع اختباره. بعدها وقف للمراجعة (نهاية المرحلة 3).
قواعد السلامة بـ CLAUDE.md إلزامية.
```

## 5) ملاحظات مهمة للي بيكمّل
- **قاعدة بيانات التطبيق هلق v6.** أي تعديل على database.dart لازم يترافق مع:
  - migration جديدة.
  - fixture للنسخة القديمة (`test/fixtures/schema_vN.sql`).
  - `dart run build_runner build`.
- **بعد إضافة أي أيقونة جديدة**، اعمل `flutter clean` قبل بناء release.
- **التاريخ بيتخزّن UTC.** المزامنة بتعتمد على جدول `sync_outbox` يلي بيتعبّى عن طريق triggers، ولازم أي جدول جديد بدو مزامنة ينضاف لـ `appendOnlyTables` أو `mutableTables` (بـ `doaya_core/lib/src/sync.dart` وبـ `backend/app/sync.py`).
- **الصيدلية الأولى للتجربة** هي صيدلية الوالدة. السيرفر بيكون كمبيوتر الصيدلية على الشبكة المحلية، وما بدنا إنترنت.
