## 1) الوضع الحالي بالضبط

| المرحلة | شو فيها | الحالة |
|---|---|---|
| 0 | الأساس، التصميم (زجاج غامق وأخضر)، `doaya_ui` | ✅ خالصة ومعتمدة |
| 1 | برنامج الصيدلية بدون إنترنت: بيع، مخزون وصلاحية، ظروف، ديون، مرتجعات، صندوق وورديات، حسابات الموظفين | ✅ خالصة |

**شو خالص بالمحاسبة (1.5):**
- المشتريات: موردين، فواتير شراء، كشف حساب، دفعات، مرتجع للمستودع.
- الأرباح والتكلفة.
- النواقص والطلبيات، مع إرسال الطلبية على واتساب.
- الجرد بدون ما يوقف البيع.

**شو خالص بالسيرفر (2):**
- سيرفر FastAPI مع PostgreSQL: حسابات، ربط أجهزة، فصل أجهزة، ومزامنة (رفع وتنزيل).
- محرّك المزامنة جوّا التطبيق، مع صندوق صادر بيتعبّى تلقائياً من قاعدة البيانات.
- شاشة «السيرفر والمزامنة»:
  - اكتشاف السيرفر على الواي فاي.
  - إنشاء الصيدلية على السيرفر، أو الربط برقم وكلمة سر.
  - مؤشّر مزامنة حقيقي بأعلى الشاشة.
  - للمالك: الأجهزة وحسابات الموظفين.
  - «انضمام لصيدلية موجودة» من أول شاشة، وحساب الموظف بيفتح لحاله.
- تجربة حقيقية على لينكس بجهازين: البيع على الجهاز التاني بيبيّن على الكاونتر.
- تجربة كاملة من أولها لآخرها مع السيرفر الحقيقي، ونجحت.
- **تشفير الواي فاي:**
  - السيرفر صار يشتغل HTTPS بشهادة بيعملها لحاله.
  - كل جهاز بيحفظ بصمة الشهادة أول ما ينربط، وبيرفض أي شهادة غيرها.
  - الرمز القصير (متل `AB12-CD34`) بيبيّن بالتطبيق وبيطبعه المركّب منشان تقارنهن.

**عدد الاختبارات:** السيرفر 34، والمنطق (`doaya_core`) 95، ونظام التصميم 23، والتطبيق 80، وفوقهم تجربة المزامنة الكاملة (على HTTPS).

**أسئلة لسا ناطرة جواب صاحب المشروع:**
1. **طباعة الإيصال** بزر صغير (محتاج مكتبتي `pdf` و`printing`). ما انعطت موافقة لسا.

## 2) تجهيز جهازك مرة وحدة

```bash
git clone https://github.com/5466676/pharmacy-app.git && cd pharmacy-app
git checkout claude/new-session-kppq6z
# Flutter stable (3.47 أو أحدث)، Dart 3.13
flutter pub get
# السيرفر: Python 3.11+، PostgreSQL 16
cd backend && python -m venv .venv
.venv/Scripts/pip install -e ".[dev]"      # على ويندوز (على لينكس: .venv/bin/pip)
# بقاعدة البيانات:
#   CREATE ROLE doaya LOGIN PASSWORD 'doaya' CREATEDB;
#   CREATE DATABASE doaya_test OWNER doaya;
```

**أوامر الفحص** (موجودة بـ `CLAUDE.md`):
- `cd packages/doaya_core && dart test`
- `cd apps/pharmacy && flutter test`
- `cd backend && .venv/bin/pytest`
- `flutter analyze`
- `./tool/sync_e2e.sh`

## 5) ملاحظات مهمة للي بيكمّل
- **قاعدة بيانات التطبيق هلق v6.** أي تعديل على database.dart لازم يترافق مع:
  - migration جديدة.
  - fixture للنسخة القديمة (`test/fixtures/schema_vN.sql`).
  - `dart run build_runner build`.
- **بعد إضافة أي أيقونة جديدة**، اعمل `flutter clean` قبل بناء release.
- **التاريخ بيتخزّن UTC.** المزامنة بتعتمد على جدول `sync_outbox` يلي بيتعبّى عن طريق triggers، ولازم أي جدول جديد بدو مزامنة ينضاف لـ `appendOnlyTables` أو `mutableTables` (بـ `doaya_core/lib/src/sync.dart` وبـ `backend/app/sync.py`).
- **الصيدلية الأولى للتجربة** هي صيدلية الوالدة. السيرفر بيكون كمبيوتر الصيدلية على الشبكة المحلية، وما بدنا إنترنت.
